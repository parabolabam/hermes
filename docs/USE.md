# Personal-use information

Hermes Assistants is the repository owner's private assistant, not an account-registration service or an offer to operate assistants for other people.

It uses accounts and trackers explicitly connected by its operator. The life role checks new mail, maintains selected trackers and sends private notifications. The coding role handles development work on demand. Drafts require human review before sending; code changes require review before merge or deployment. Model judgments and ambiguous remote operations require the operator's review.

The operator controls hosting, model subscriptions, account permissions, retention and revocation. External providers' applicable account terms remain in effect. See the [data-use notice](PRIVACY.md) and [operating instructions](../README.md).
